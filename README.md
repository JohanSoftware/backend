# 📌 Actividad 4 - Diseño del prototipo

## 🧾 Descripción

Este repositorio contiene el desarrollo del **backend** del sistema de gestión de residuos enfocado en comunidades urbanas.

El objetivo del sistema es facilitar la organización, seguimiento y disposición adecuada de residuos mediante herramientas tecnológicas como reportes, autenticación de usuarios y visualización de información.

El backend está construido siguiendo una arquitectura cliente-servidor y documentado mediante Swagger, en cumplimiento de los requisitos funcionales del proyecto.

---

## ⚙️ Tecnologías utilizadas

* Node.js
* Express
* PostgreSQL
* Swagger (OpenAPI)
* ESLint & Prettier

---

## 🚀 Funcionalidades principales

* Registro e inicio de sesión de usuarios
* Creación y consulta de reportes de residuos
* Estructura base para gestión de información ambiental
* Documentación de la API con Swagger

## ▶️ Ejecución del proyecto

1. Instalar dependencias:

```
npm install
```

2. Ejecutar en modo desarrollo:

```
npm run dev
```

3. Acceder a la API:

```
http://localhost:3000
```

4. Documentación Swagger:

```
http://localhost:3000/api-docs
```
